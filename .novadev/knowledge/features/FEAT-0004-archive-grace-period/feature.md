# FEAT-0004 — Archive with a grace period

## What it does

- A batch whose every todo carries a terminal record (completed, failed, confirmed — a
  pending `ai_needstest.md` gate is not terminal) and that nobody holds the lock of gets
  `completed.md` at its root: "finished, do not add work here". It stays in `todos/` for
  `archiveGraceDays` (`novadev.json`, default 3) so recent work stays visible and the day's
  batch numbers stay obvious, then the next `novadev sync` moves it to
  `archive/<year>/todos/<batch>/`. A batch that reopens loses its marker.
- A test task whose round is `reviewed` moves to `archive/<year>/totest/<task>/rev<N>-<date>/`
  immediately.
- `novadev archive <batch>…` archives named batches now; `novadev archive --done` sweeps
  everything finished. Both regenerate the derived link files the move changes.

## How it works

`src/archive.ts`: `sweepDone` (rounds, then `sweepBatches`, then derived regeneration via
`auditLinks`) is what `novadev sync` calls; `archive()` is the thin CLI. A name collision in
the archive stops with the next free number to rename to.
